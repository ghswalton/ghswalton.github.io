📁 Google Drive Sync (2 PCs — Different Accounts):

Your PC and school PC use different Google accounts, so Drive does NOT auto-sync between them. Use folder sharing (one-time setup):

  1. On YOUR PC: In Google Drive, create a folder named "Timetable Sync".
  2. Right-click the folder → Share → add ghswaltonlahore@gmail.com as Editor → Send.
  3. On SCHOOL PC: Open Google Drive → "Shared with me" → right-click "Timetable Sync" → "Add shortcut to Drive".
  4. Export Data on your PC → save timetable-sync-data.json into the "Timetable Sync" folder. It will appear on the school PC automatically via the shared folder.
  5. On school PC: Click Import Data → select the file from the shared folder.
